= Guia de Atualização do Banco de Dados de Items - Core Keeper

== 📋 Resumo das Mudanças

Este guia documenta as melhorias realizadas no processo de extração e validação de items do Core Keeper.

=== ✨ Melhorias Implementadas

* **scripts/items.py** - Versão melhorada com:
  - Tratamento robusto de erros com try-catch em pontos críticos
  - Validação abrangente de dados durante a extração
  - Sistema de relatório detalhado com estatísticas
  - Logging estruturado com timestamps
  - Classe `ItemExtractionReport` para rastreamento de progresso
  - Melhor tratamento de casos extremos e objetos inválidos

* **scripts/test_items.py** - Novo script de validação com:
  - Testes estruturados de integridade de dados
  - Validação de estrutura JSON
  - Verificação de campos obrigatórios
  - Análise de propriedades especiais (dano, cooldown, condições, etc.)
  - Validação de índices de ícones
  - Verificação de arquivo spritesheet
  - Geração automática de relatório de testes

== 🚀 Como Usar

=== Pré-requisitos

[source,bash]
----
python3 -m venv ./venv
pip install -r requirements.txt
----

=== Passo 1: Extrair Assets do Core Keeper

[source,bash]
----
# 1. Abra AssetRipper no Windows
# 2. File > Open Folder > Selecione a pasta do Core Keeper
#    Local padrão: C:\Program Files (x86)\Steam\steamapps\common\Core Keeper
# 3. Export > Export all Files > Selecione a pasta ./dump
----

=== Passo 2: Executar o Script de Extração

[source,bash]
----
cd scripts
python3 items.py
----

O script irá:
- Carregar dados do PugDatabase
- Extrair texturas e metadados
- Processar todos os items
- Gerar spritesheet
- Salvar dados em `out/item/item-data.json`
- Criar relatório de extração em `out/item/extraction_report.txt`

=== Passo 3: Validar os Dados Extraídos

[source,bash]
----
python3 test_items.py
----

O script de validação irá:
- ✓ Verificar integridade do JSON
- ✓ Validar estrutura de items
- ✓ Validar set bonuses
- ✓ Verificar índices de ícones
- ✓ Analisar propriedades especiais
- ✓ Validar spritesheet
- ✓ Gerar relatório em `out/item/validation_report.txt`

=== Passo 4: Copiar Dados para o Projeto

[source,bash]
----
./deploy.py
----

Ou manualmente:
[source,bash]
----
cp out/item/item-data.json ../src/assets/item-data.json
cp out/item/item-spritesheet.png ../src/assets/item-spritesheet.png
----

== 🐛 Troubleshooting

=== O script items.py não encontra os dados

*Problema:* `FileNotFoundError: dump/CoreKeeper/...`

*Solução:* 
- Verifique se você exportou os arquivos do Core Keeper com AssetRipper
- A pasta `dump` deve estar no mesmo diretório que `scripts/items.py`
- Certifique-se de que a exportação foi completa

=== O arquivo JSON está corrompido

*Problema:* `json.JSONDecodeError`

*Solução:*
- Execute `python3 test_items.py` para validar
- Verifique se há erros no `extraction_report.txt`
- Tente executar `items.py` novamente

=== Alguns items estão faltando

*Problema:* Total de items menor que esperado

*Solução:*
- Verifique o `extraction_report.txt` para ver quantos items foram pulados
- Itens podem ser pulados se:
  - Não têm tradução (veja "No Translation")
  - Não têm ícone (veja "No Image Found")
  - Estão na blacklist (veja "Blacklisted Items")
  - São duplicatas (veja "Duplicates Skipped")

=== O spritesheet está danificado

*Problema:* Imagem não carrega ou está cortada

*Solução:*
- Verifique o `validation_report.txt`
- Execute `python3 test_items.py` para validar o spritesheet
- Certifique-se de que `out/item/item-spritesheet.png` existe
- Tente regenerar executando `items.py` novamente
